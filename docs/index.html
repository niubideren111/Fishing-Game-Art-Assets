常见问题

美术资源和捕鱼源码是同一项目吗？

不是。本项目提供美术素材展示与样例；客户端和服务端代码片段见捕鱼源码项目。

导入素材时应保留哪些文件？

同一组 PNG、atlas 和 JSON 应一起保留，并核对项目动画运行库的版本。
