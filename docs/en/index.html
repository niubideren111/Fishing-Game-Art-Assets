Frequently asked questions

Is this the same as the fishing source-code repository?

No. This repository is for art samples; the related source repository contains client configuration and C++ server excerpts.

Which files belong together?

Keep each matching PNG, atlas and JSON set together and verify the animation runtime version used by your project.
